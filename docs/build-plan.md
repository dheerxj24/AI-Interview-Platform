# Build plan

1. Week 1: Backend core. FastAPI app, Postgres schema and migrations, CRUD for problems and sessions, unit tests. Deliverable: API docs page with working endpoints.
2. Week 2: Sandbox and execution. Dockerized Python runner with CPU, memory, and timeout limits. Celery worker runs submissions and stores runs. Deliverable: submit code, get pass counts back.
3. Week 3: Live editor. React editor with WebSocket sync, presence, and autosave. Deliverable: two browsers see the same code in real time.
4. Week 4: Scoring and AI co-pilot. Scorecard and summary page. One LLM feature: suggest follow-up questions from the candidate's code. Deliverable: a full mock interview.
5. Week 5: Ship it. Docker Compose for the full stack, GitHub Actions for tests and lint, deployed demo, README with architecture diagram. Deliverable: public link and a 3-minute demo video.
